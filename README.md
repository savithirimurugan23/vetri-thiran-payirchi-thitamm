# Student Enrollment & Course Management System (SECMS)
### Vetri Thiran Payirchi Thittam - Salesforce Admin Project

**Student:** Savithiri Murugan  
**Repo:** vetri-thiran-payirchi-thitamm

### Project Objective
College students-a course-ku enroll pannurathukku Salesforce la oru automated system.

### Objects Created
1. **Student__c** - Student details (Name, Email, Phone, Dept)
2. **Course__c** - Course details (Name, Fees, Duration, Seats)
3. **Enrollment__c** - Student + Course join pannura junction object

### Features Implemented
- Student Registration with Phone Validation (10 digits)
- Course Management (Java, Python, Salesforce)
- Auto Fees Calculation using Trigger
- Seat Availability Check
- Enrollment Status Tracking
- Email Alert via Flow

### Technologies
Salesforce Object Manager, Validation Rules, Flow, Apex Trigger
